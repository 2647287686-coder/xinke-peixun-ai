拓店人员试岗期 AI 陪伴助手

规划框架 · 喜客丸拓店岗 · 2026.08
核心机制：账号由总部后台代建（录入入职日期 + 分配岗位）→ 新人在「新员工必读」板块分类自学（产品 / 抖音来客云连锁 / 门店入驻流程（含异议话术） / 仅售预包装备案，不按天强制、完成即标记已学 / 待学，须学完所有板块方可参加总部开启的考试）→ 总部在账号管理页随时指定开启 20 题随机测验（满分 100 / 20 分钟 / 考中不显答案 / 可断点续答 / 考后显答案+分数）。小助手的入职辅助职责止于这次考试；考试之后的实操考核、过程跟踪与红线判定由专人线下跟进，本助手不做红线预警 / 实操辅助 / 过程量看板。

维度衡量指标（KPI）

职责边界小助手仅覆盖「学习完成」+「知识掌握（考试）」；实操达标、过程合规、行为红线、用人决策（通过/淘汰）均由专人线下跟进，本助手不提供红线预警、过程量看板、登记表导出等功能

4功能模块分层（围绕 7 天试岗）

A · 引导层（账号与考试入口，少靠老人口头交代）
  • 账号生命周期：由总部后台代建账号（录入入职日期 + 分配岗位）→ 总部在账号管理页随时指定开启考试
  • 「新员工必读」板块 ★核心：4 个分类学习模块（产品 / 平台 / 入驻含异议话术 / 备案），员工学完点"标记已学完"翻为已学习、未学显示待学习，进度追踪（不按天强制）；须全部已学完，总部开启的考试入口才出现
  • 考试开启提醒：总部在账号管理页点击"开启考试"后，员工端即时出现考试入口（20 题 / 20 分钟 / 可断点续答）
B · 学习层（「新员工必读」板块内容，前 3 天集中自学、完成即标记）
  • 6 款肉丸产品卡（名称 / 卖点 / 配料 / 适用人群 / 30 秒话术）
  • 抖音来客云连锁知识库：基础概念 + 门店准入 5 条准则 + 6 大优势话术
  • 门店入驻流程手册：资质准备 / 品牌授权 / 提交步骤 / 常见驳回处理 / 异议处理话术（"没兴趣"/"已有平台"/"不会操作"/"抽佣高"）
  • 仅售预包装食品备案流程（帮店主办理用）
C · 问答基础（始终可用，非本次新增）
  • 小助手本体即 AI 问答（基于培训资料库 + 联网核验），新员工随时提问产品 / 平台 / 入驻问题
D · 管理层（考核决策 + 红线预警）
  • 后台新建员工账号模块：总部代建账号、录入入职日期、分配岗位，可单个或批量创建并下发临时密码
  • 员工账号详情页 ★核心：聚合展示该员工 学习详情（必读 4 个板块 已学/待学 + 完成进度）+ 考试分数与逐题详情 + 实操进度，总部一眼看清培训状态
  • Day 3 20 题选择测验模块 ★核心：总部在账号管理页指定开启，30 题题库均衡抽 20 题、满分 100、20 分钟限时、到点自动结算、断点续答（服务端存抽题/作答/截止时间）；考后显示正确答案+分数；员工账号详情页展示分数与逐题详情，后台按人/按题查看错题分布
  • ⚠️ 不做：实过程量看板、登记表汇总/导出、淘汰红线预警（考试之后的跟进由专人线下负责，本助手职责止于考试）

注：4 条淘汰红线（虚假拜访 / 飞单切单 / 连续 2 天过程量为 0 / 不服从管理）仍为公司制度，由专人线下传达与判定；本助手不提供红线预警功能。

5知识内容维护（数据驱动）

现状：培训资料为扁平 txt 文档，由 BM25 检索 + 联网核验支撑 AI 问答。

「新员工必读」与考试题库的维护机制（已落地）：

  • 必读板块内容（`onboarding-modules.json`）+ 考试题库（`quiz-bank.json`）均为结构化数据，后台「培训内容管理」可在线编辑
  • 内容同步：你后续更新资料库时，同步更新这两个数据源即可——板块内容随资料扩充、题库随资料更新而丰富，考试始终从题库随机抽 20 题

注：分类标签 / 岗位关联 / 知识底座重构等更重的演进（原 P4）已取消，不在本次范围。
