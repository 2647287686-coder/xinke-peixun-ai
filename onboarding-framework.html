拓店人员试岗期 AI 陪伴助手

规划框架 · 喜客丸拓店岗 · 2026.08
核心机制：账号由总部后台代建（录入入职日期 + 分配岗位）→ 7 天试岗 = 前 3 天在「新员工必读」板块分类自学（产品 / 抖音来客云连锁 / 门店入驻流程（含异议话术） / 仅售预包装备案，不按天强制、完成即标记已学 / 待学，须学完所有板块方可参加总部开启的考试；由总部在账号管理页随时指定开启 20 题随机测验：满分 100 / 20 分钟 / 考中不显答案 / 可断点续答） + 后 4 天实操考核（12 家拜访 + 1 家成功入驻 + Day6 短会）→ 总部判定 通过转正 / 触发红线即淘汰。AI 全程按天引导、按项提醒、按红线预警；账号详情页聚合展示学习 / 考试 / 实操状态。

4功能模块分层（围绕 7 天试岗）

A · 引导层（按天按项推送，少靠老人口头交代）
  • 账号生命周期：由总部后台代建账号（录入入职日期 + 分配岗位）→ 总部在账号管理页随时指定开启考试 → Day 4 起进入实操跟踪
  • 「新员工必读」板块 ★核心：4 个分类学习模块（产品 / 平台 / 入驻含异议话术 / 备案），员工学完点"标记已学完"翻为已学习、未学显示待学习，进度追踪（不按天强制）；须全部已学完，总部开启的考试入口才出现
  • 考试开启提醒：总部在账号管理页点击"开启考试"后，员工端即时出现考试入口（20 题 / 20 分钟 / 可断点续答）
  • Day 4–7 每日拜访提醒（≥ 3 家、20:00 前提交登记表、跑通 1 家入驻倒计时）
  • Day 6 上午 10:00 短会提醒（整理问题 / 汇报跑店情况）
B · 学习层（「新员工必读」板块内容，前 3 天集中自学、完成即标记）
  • 6 款肉丸产品卡（名称 / 卖点 / 配料 / 适用人群 / 30 秒话术）
  • 抖音来客云连锁知识库：基础概念 + 门店准入 5 条准则 + 6 大优势话术
  • 门店入驻流程手册：资质准备 / 品牌授权 / 提交步骤 / 常见驳回处理 / 异议处理话术（"没兴趣"/"已有平台"/"不会操作"/"抽佣高"）
  • 仅售预包装食品备案流程（帮店主办理用）
C · 问答层（实操路上随时问，已有能力增强）
  • 多轮追问：跑店途中遇到问题连续追问，不必重述背景
  • 知识盲区收集 ★反哺闭环：汇总检索为空 / 被点👎 的问题 → 后台"待补充知识"清单
  • 语音输入：跑店路上手忙，问答直接说
D · 管理层（考核决策 + 红线预警）
  • 后台新建员工账号模块：总部代建账号、录入入职日期、分配岗位，可单个或批量创建并下发临时密码
  • 员工账号详情页 ★核心：聚合展示该员工 学习详情（必读 4 个板块 已学/待学 + 完成进度）+ 考试分数与逐题详情 + 实操进度，总部一眼看清培训状态
  • Day 3 20 题选择测验模块 ★核心：总部在账号管理页指定开启，30 题题库均衡抽 20 题、满分 100、20 分钟限时、到点自动结算、断点续答（服务端存抽题/作答/截止时间）；考后显示正确答案+分数；员工账号详情页展示分数与逐题详情，后台按人/按题查看错题分布
  • 实过程量看板：12 家拜访进度 + 1 家入驻进度，按人可视化
  • 每日登记表汇总 / 导出 Excel
  • 淘汰红线预警：检测到疑似虚假拜访 / 连续 2 天过程量为 0 等情形自动告警
触发即淘汰的 4 条红线（必须让新人提前背熟）
  • 虚假拜访：伪造定位打卡 / 伪造商家信息 / 对紧闭店门头拍照
  • 飞单 / 切单：将公司意向客户转移给外部代理商
  • 连续 2 天过程量为 0 或无故旷工
  • 不服从管理：不按规范要求执行，脱离总部行动且没有有效工作量

5知识底座演进

现状：扁平 txt，无分类、无岗位关联。

升级方向：

  • 分类标签：产品 / 平台知识 / 入驻流程 / 备案流程 / 话术 / 红线 / 制度，检索可按类筛选
  • 岗位关联：每篇资料标注适用岗位（拓店岗 / 门店岗 / 总部），按岗精准推送
  • 时效标记：备案流程 / 入驻政策等可能更新的资料加有效期，过期自动提醒
  • 新增结构化数据：①6 款肉丸产品卡（名称/卖点/配料/适用人群/30 秒话术）②门店准入 5 条准则 ③入驻流程步骤化 ④4 条淘汰红线
  • 内容同步机制：「新员工必读」板块内容与考试题库均为数据驱动（结构化文件 `onboarding-modules.json` + `quiz-bank.json`，后台「培训内容管理」可在线编辑）；你后续更新资料库时，同步更新这两个数据源即可——板块内容随资料扩充、题库随资料更新而丰富，考试始终从题库随机抽 20 题
