品牌总定位（一句话版）
一．广州日报旗下&喜客丸双品牌・药食同源养生肉丸开创者
以国医大师食疗智慧 + 道地滋补食材，把 “难坚持、难炖煮、难入口” 的传统养生，变成好吃、方便、全家可吃的日常肉丸。
二．核心战略定位
品类定位中国首创养生肉丸品类，不是普通肉丸，是可当汤料、可当主菜、可日常滋补的功能性食品。
三．价值定位把养生变日常，把滋补变美味
1. 不用煲 → 5 分钟即食
2. 不苦涩 → 好吃不腻
3. 不燥热 → 温和全家吃
4. 不添加 → 配料干净放心
四．人群定位全年龄段养生家庭
1. 主力：25–60 岁家庭决策者（宝妈、主妇、长辈）
2. 重点：熬夜党、上班族、中老年人、术后 / 月子人群
3. 覆盖：老人、小孩、送礼人群、社区 / 园区 / 工厂刚需人群
五．场景定位三餐养生 + 火锅聚餐 + 健康送礼
1. 日常：快手汤、早餐、简餐
2. 社交：火锅、打边炉、家宴
3.礼赠：长辈、产妇、客户、商务伴手
六．6款产品矩阵定位（清晰不打架）

邓老食疗・健脾祛湿・椰香清润

卖点：国医大师背书、河源道地、补而不燥
2. 西洋参肉丸（轻滋补款）
加拿大西洋参・补气养阴・抗疲劳
定位：职场熬夜提神丸
卖点：不燥热、提神、加班 / 备考友好
3. 灵芝肉丸（高端养生款）
紫灵芝・不苦版・双倍精华
定位：免疫力增强丸
卖点：唯一不苦灵芝、超细粉、术后 / 长辈首选

七.品牌差异化定位（别人抄不走）
双权威背书广州日报「广报悦香」品牌公信力 + 国医大师邓铁涛食疗传承

2.解决养生三大痛点
怕苦 → 我们不苦
怕麻烦 → 5 分钟即食
